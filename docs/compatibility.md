# Porting the Clock Contract

The category and instance identify a nominal clock, with the map supplied by composition. One source may feed several logical domains. An Adapter should disclose oscillator tolerance, available divisors and any derived domains that change together. Hardware Definitions supply clock topology and fixed characteristics. The effective configured rate is runtime information.

This repository's host simulations and shared API compile/link checks provide source-level evidence. Target timing and physical behavior require hardware validation.
